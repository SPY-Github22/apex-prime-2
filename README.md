An immersive 3D open-world space exploration, combat, and trading simulator built with Three.js and TypeScript. Pilot customizable starships across contiguous stellar sectors, dogfight rogue AI swarms, dodge asteroid fields, dock at orbital trading stations, and complete dynamic NPC missions.

---

## 🕹️ Key Features

- **🚀 6-DOF 3D Flight Physics**: Smooth Newtonian inertia, pitch, yaw, roll with banking, afterburners, and evasive barrel rolls.
- **🌌 Open-World Space Sectors**: Dense asteroid fields, orbital megastructures, and dynamic celestial illumination.
- **⚔️ 3D Combat & Ballistics**: Plasma blasters, homing missiles, lead-target indicators, shield deflectors, and explosive particle physics.
- **🛰️ Orbital Space Stations & NPCs**: Automated docking tractor beams, interactive station shopkeepers, equipment upgrades, and dynamic quest boards.
- **🎵 Procedural 3D Audio**: Immersive Web Audio synthesizer producing spatialized engine rumbles, laser bursts, and atmospheric synthwave score.

---

## 🛠️ Tech Stack

- **Graphics & 3D**: Three.js (r160+) WebGL
- **Language**: TypeScript 5 (Strict Mode)
- **Bundler**: Vite 5
- **Unit Testing**: Vitest
- **CI/CD**: GitHub Actions deploying to GitHub Pages
